# Maintainers

This file lists who maintains `LMCache/lmcache-blogs` and what that role
covers.

## Current maintainer

| Name | GitHub | Email | Role |
|---|---|---|---|
| Karsten Wade | [@quaid](https://github.com/quaid) | quaid@iquaid.org | Owner and lead maintainer |

## What the maintainer does

- Reviews and merges pull requests. `.github/CODEOWNERS` requests a review
  from the maintainer on every PR.
- Owns the editorial board,
  [`orgs/LMCache/projects/6`](https://github.com/orgs/LMCache/projects/6),
  and its columns, labels, and routing.
- Owns the repository settings, the `PROJECT_TOKEN` secret, and the
  `BOARD_NUMBER` variable.
- Owns `AGENTS.md`, the agent policy for this repo.
- Answers questions from contributors and editors, and decides when the
  process docs and templates change.

## Ask a question

Open an issue in this repository, or mention @quaid in an issue or pull
request.

To report a security problem, follow [`SECURITY.md`](SECURITY.md). Do not
open a public issue.

## Become a maintainer

Contribute to the pipeline or the editorial process for a while, then ask in
an issue. The current maintainer adds new maintainers to this file and to
`.github/CODEOWNERS` in a pull request.
